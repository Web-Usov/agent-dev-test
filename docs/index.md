## Spec-first

Шаблоны спецификации находятся в `specs/_template/`:

- `spec.md` — что и зачем строим;
- `plan.md` — как реализуем;
- `tasks.md` — как декомпозируем работу.

## GitHub Pages

Публикация документации не является частью обязательного CI. Workflow запускается вручную из GitHub Actions и предназначен только для статической документации.

Перед первым запуском нужно включить GitHub Pages для репозитория с источником **GitHub Actions** в настройках репозитория.
